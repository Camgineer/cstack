# Develop C-Stack

## Install

```sh
codex plugin marketplace add /Users/cameron/repos/cstack
codex plugin add cstack@cstack-local
```

Start a fresh task after install so the task receives the current skill catalog. Invoke `$cstack:setup-bot` with a purpose and review the proposed bot identity before record creation.

Disable overlapping copies of the same PStack, Team Kit, or Matt Pocock workflow in the task that uses C-Stack.

## Updates

Commit source changes after checks. Push to the private origin for backup. Refresh the local marketplace and reinstall C-Stack with supported plugin commands. Test in a fresh task.
