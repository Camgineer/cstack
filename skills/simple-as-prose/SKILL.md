# Simple as prose

Apply this standard every time you write prose for a person or another agent. Preserve the meaning, facts, required terms, tone, and constraints.

## Set the job

Before drafting, determine the reader, shared context, desired outcome, and next action. Do this silently unless missing information would change the result.

## Write the point first

- Lead with the result, decision, risk, or request.
- Give each sentence one main idea.
- Prefer active voice, present tense, concrete nouns, and strong verbs.
- Use the shortest familiar word that preserves the meaning.
- Keep necessary technical terms. Explain them when the reader may not know them.
- Name the owner, action, timing, blocker, and proof when they affect what happens next.
- Replace vague claims with facts, examples, numbers, names, or observable criteria.
- Give each concept one name and use that name throughout.
- Vary sentence length. Keep the rhythm natural without making the reader backtrack.
- Keep useful warmth, humor, emotion, and opinion when they help the message.

## Match the prose to its job

- Keep chat and status updates short. Report the result before the process.
- Write requests so the reader can act without guessing.
- Write procedures as direct commands. Put the condition before the instruction. Use numbered lists only for sequences.
- Keep reference material factual and complete. Keep persuasion and opinion out of it.
- Explain one bounded topic through its real cause, constraints, tradeoffs, and consequences.
- Make tutorials produce a visible result early. Tell the reader what they should see.
- Keep code comments only for rationale, external constraints, protocol details, or measured tradeoffs that the code cannot state.

## Remove AI tells

- Delete filler openings, throat-clearing, repeated conclusions, generic encouragement, and empty summaries.
- Delete stock chatbot phrases such as "Of course," "Certainly," "I hope this helps," and "Let me know if."
- Replace inflated words with plain words. Prefer "use" to "utilize," "help" to "facilitate," and "is" to "serves as."
- Remove stock AI words when a concrete word fits. Common offenders include "additionally," "crucial," "delve," "enhance," "foster," "intricate," "landscape," "pivotal," "showcase," "tapestry," "testament," "underscore," and "vibrant."
- Remove empty phrases that end in "ing," such as "highlighting," "ensuring," and "showcasing," unless they name a real action and actor.
- Name the source of a claim. Delete vague attributions such as "experts believe" when no source exists.
- State the point directly instead of using "not just X, but Y."
- Use the natural number of items. Do not force ideas into groups of three.
- Repeat the correct term instead of cycling through synonyms.
- Replace abstract metaphors and promotional language with the actual mechanism, behavior, or fact.
- Remove adverbs that prop up weak verbs. Use a stronger verb or a measured fact.
- Write complete sentences. Do not compress prose into fragments, arrows, or symbol-heavy shorthand.

## Keep punctuation quiet

- Use periods and commas for normal separation.
- Never use an em dash, an en dash, or a hyphen as a dash substitute. Start a new sentence or use a comma.
- Use a colon only before a real list or example.
- Use straight quotation marks.
- Use headings, bold text, and lists only when they make the text easier to scan.
- Keep headings in sentence case.
- Skip decorative emoji.

## Edit before sending

1. Check that the first sentence gives the reader useful orientation.
2. Cut every word and sentence that adds no meaning, evidence, necessary tone, or context.
3. Split any sentence that carries two thoughts or makes the reader backtrack.
4. Fix ambiguous pronouns, modifiers, conditions, and list groupings.
5. Scan for filler, inflated language, stock phrasing, vague claims, and repeated meaning.
6. Search the final text for em dash and en dash characters. Replace every match.
7. Read the result once at normal speed. Revise anything that sounds scripted, stiff, or vague.

## Return the right artifact

- For a rewrite, return the improved text. Explain changes only when the explanation helps.
- For a critique, name the main clarity problems, provide the revision, and list the few rules that mattered most.
- For a draft, infer the reader and outcome. Produce the shortest complete version that works.
- For ordinary conversation, answer directly. Do not describe this editing process.

## Completion check

The work is complete only when all of these statements are true:

- The reader can understand the point on the first pass.
- The next action is explicit when one exists.
- Every claim is accurate, sourced, measured, or clearly labeled as an inference or guess.
- Every sentence earns its place.
- The prose sounds like a capable person wrote it for this reader.
- The text contains no em dash or en dash characters.
